1. Создадим контейнер из образа Ubuntu.
2. Запустим созданный контейнер.
3. Для того, чтобы получить работающий контейнер, ему необходимо передать какую-то задачу, например:
    docker run -d --name my_ubuntu_container ubuntu tail -f /dev/null

4. Остановим работающий контейнер.
5. Перезапустим остановленный контейнер.
6. Удалим контейнер.

7. Проверьте, что происходит в docker desktop, выполнив операции пунктов 4-6 в UI (user interface).
   Посмотрите на список контейнеров.
