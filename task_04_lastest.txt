1. Запустите команду для отображения списка всех образов Docker на вашей системе.

2. Выберите один из образов из списка и запустите команду для просмотра истории его изменений.

3. Выберите образ и выполните команду для получения подробной информации о нем.

4. Создание образа из контейнера:
    - Запустите контейнер из ранее созданного образа Ubuntu.

    - В корне контейнере создайте новый файл text.txt c любым содержимым.

    - Затем выполните команду для создания нового образа на основе изменений в контейнере

    - Чтобы убедиться, что файл сохранился в новом образе, запустите из него новый контейнер.

    - И проверьте наличие файла.

5. Выберите один или несколько образов из списка и выполните команду для их удаления.
